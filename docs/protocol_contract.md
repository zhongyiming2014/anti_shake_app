# 防抖笔 BLE 协议占位约定

硬件尚未定型时，软件内部先统一以下逻辑结构。所有 `TODO` 项必须在真机联调前由硬件组确认。

## GATT

| 名称 | 属性 | 用途 |
|---|---|---|
| `ANTI_SHAKE_SERVICE` | Service | 主服务 UUID，TODO |
| `SENSOR_DATA` | Notify | 六轴数据、震颤强度、序号 |
| `DEVICE_STATUS` | Read/Notify | 电量、温度、阻尼、故障码 |
| `CONTROL` | Write | 开始、停止、校准、设置阻尼 |
| `COMMAND_ACK` | Notify | 命令序号、结果、实际执行值 |

## 传感器数据

- 时间戳：毫秒，TODO 确认由手机还是 ESP32 产生
- 加速度：`ax/ay/az`，单位 TODO
- 角速度：`gx/gy/gz`，单位 TODO
- 震颤强度：建议 ESP32 输出 `0.0-1.0`
- 阻尼等级：建议使用归一化整数 `0-100`
- 序号：用于计算丢包率

高频数据建议使用固定长度二进制帧。不要在 50-100 Hz 下持续发送 JSON。

## 安全约束

- App 只发送归一化阻尼等级，不直接发送线圈电流。
- ESP32 必须执行最终限幅、温度保护和故障保护。
- App 只有收到匹配序号的 ACK 后才确认设置成功。
- 断线或超时不得继续显示“设置成功”。
